# Rally On 디자인 리뉴얼 · 2026-10-10

## 목표와 범위

20–30대 테니스 입문자가 자기 수준을 편안하게 표현하고, 일시·장소·참가 조건을 비교한 뒤 신청하도록 돕는다. 사용자 요청으로 네이티브 실기기 검증을 잠시 중단하고 기존 웹 UI를 갱신한다. 기능 확장보다 기존 흐름의 시각적 위계와 공통 컴포넌트를 먼저 개선한다. 인증·추천 점수·모집 정원·입금·환불 정책과 서버 계약은 변경하지 않는다. 기존 Claude 변경과 mobile/prototype은 보존한다.

## 브랜드 / 토큰

컨셉: **처음 만나는 사이, 편하게 이어지는 랠리.** 따뜻하고 차분하되 운동 서비스의 명확한 에너지를 유지한다. 랭킹이나 고급 클럽보다 초보자의 편안함을 우선한다.

- Court green `#174C3C`: 주요 행동, 선택, 브랜드.
- Ball lime `#D9ED92`: 포인트·장식. 본문이나 흰색 텍스트 배경으로 쓰지 않는다.
- Warm white `#F7F8F2`, white `#FFFFFF`: 바탕·표면.
- Ink `#202D27`, secondary `#5D6B62`, border `#DFE5DD`.
- 기능 상태는 텍스트와 병기. 오류 red, 주의 amber, 플레이 성격은 작은 색상 태그.
- Pretendard / 시스템 한글 폰트. 본문 15–16px, 메타 12–13px, 제목 24–32px. 숫자 일정·금액은 등폭.
- 여백 4/8/12/16/24/32. 페이지 좌우 20–24, 버튼 높이 48–52, 터치 영역 최소 44. 카드 20px, 입력 14px, 배지 8px.
- WDS의 포커스 트랩·모달·로딩·disabled 동작 유지. 기존 CSS layer 격리를 유지하고 semantic CSS 변수만 브랜드에 맞게 재정의한다.

## 흐름

첫 진입(혜택·카카오·운영자 보조 경로) → 닉네임 → 경험 → 랠리 → 게임 경험 → 원하는 플레이/성별 → 프로필 요약 → 매칭 목록 → 상세 → 신청 → 내 활동/채팅.

온보딩 API의 실제 입력은 닉네임 + 질문 4개이며 마지막 질문에서 필수 성별도 받는다. 오래된 `07-m2` 문서의 지역 질문은 현행 코드에 없다. 이 작업에서 지역 수집을 다시 추가하지 않는다. 완료 화면에 실제 선택값을 요약하고 가상의 레벨을 만들지 않는다.

일반 매칭은 신청과 수락, 코트 매칭은 승인→이체→운영자 확인을 구별한다. 중요한 기한·취소환불 고지는 디자인 단순화를 이유로 숨기지 않는다.

## 이미지

`public/images/brand/welcome-court.webp`: 내장 imagegen으로 생성한 편안한 테니스 랠리 일러스트. 모델 선택 매개변수가 없어 사용자가 언급한 GPT 2.5를 지정/검증하지 못했다. 실제 코트 증빙이나 사진으로 사용하지 않는다. UI 아이콘은 기존 Phosphor를 사용해 일관성과 작은 크기 가독성을 지킨다.

프롬프트: 성인 초보자 두 명이 forest green 코트에서 편하게 랠리하는 장면, warm ivory 배경, lime 공, 절제된 cut-paper/gouache editorial 스타일, 3:2, 텍스트·로고·트로피 없음.

## 검증 및 제안서

실제 UI를 공유하는 개발 전용 미리보기와 `docs/design/rally-on-v2/index.html` 제안서에서 변경을 확인한다. 미리보기의 예시 데이터는 운영 DB에 저장하지 않는다. 코드 검증 결과와 실기기 미검증 범위를 완료 시 기록한다. 배포와 네이티브 앱 재설치는 별도 실행 전까지 완료로 표시하지 않는다.

### 적용 결과와 검증 기록

- 첫 진입·온보딩, 매칭 홈·목록·상세를 갱신했다. 프로필 완료 요약은 실제 선택값을 표시한다.
- 개설·코트 매칭·마이·채팅은 공통 토큰과 카드·문구·간격을 정리했다. 모든 운영/금융 상태별 화면을 새로 설계한 것은 아니다.
- 공통 WDS 버튼은 브랜드 색과 최소 높이를 적용하고, 내비게이션은 활성 링크와 미읽음 배지를 유지했다.
- 개발 전용 `/design-preview`는 실제 컴포넌트에 예시 데이터만 전달한다. 실제 신청·저장을 수행하지 않으며 production에서는 `notFound()`를 반환한다.
- `npm run lint`, `npm run typecheck`, `npm run build` 통과.
- `npm run test`: 59개 파일·410개 테스트 통과, DB 환경 조건에 따른 3개 파일·110개 테스트 skipped. 운영 DB 검증을 수행했다는 의미가 아니다.
- 320px/390px 가로 넘침 없음, 1280px에서 시작 콘텐츠 최대 너비 480px 확인. 선택 전 다음 버튼 비활성, 선택 후 다음 질문 이동, 신청 시트 입력·200자 제한·닫기·예시 제출 확인. 확인한 미리보기 콘솔 오류 없음, 모달의 중첩 heading 없음.
- HTML 제안서: `docs/design/rally-on-v2/index.html`. 레퍼런스 원본 링크·로컬 이미지, 화면별 인터랙티브 설명, 디자인 토큰, 검증/후속 범위를 포함한다. 같은 디렉터리의 자산을 함께 유지한다.
- 실제 iPhone의 키보드·안전 영역·로그인·외부 앱 복귀와, 실제 계정의 신청/수락/입금/환불 전체 흐름은 이번 로컬 디자인 검증에서 실행하지 않았다. 운영 배포·앱 재설치도 아직 수행하지 않았다.
- 루트 린트에서 네이티브 시제품의 생성된 iOS/Android/www 산출물을 제외했다. 기존 mobile 소스 및 Claude 변경 내용은 수정하지 않았다.
