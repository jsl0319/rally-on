위 이미지는 조사 근거이며 아이콘 소재로 사용하지 않았습니다. 사용자께서 제공한 테니스 앱 폴더는 아이콘을 여러 앱 사이에서 구분하는 맥락으로 참고했습니다. 선호도나 인지도 개선 효과가 검증됐다는 의미는 아닙니다.
