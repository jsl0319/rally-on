# 소규모 운영용 외부 푸시 검토

2026-10-10. 조사·제안이며 구현/가입/외부 발송은 하지 않았다.

## 사용자 문제와 최소 범위

입금·확정·경기 취소를 앱 밖에서도 알아야 참가자와 운영자가 이동/대관을 결정할 수 있다.
현재 앱은 DB의 인앱 알림만 제공하며 manifest·service worker·push subscription은 없다.
크론은 기한에 상태를 처리하는 장치이고 푸시는 생성된 결과를 기기로 보내는 장치다.
푸시를 추가해도 미실행 크론의 판정 결과가 저절로 생성되지는 않는다.

## 무료 선택지

1. **표준 Web Push + 홈 화면 웹앱 권장.** 기존 Next 서버와 DB를 유지하고 브라우저 푸시 서비스에 전달한다. Apple Developer 유료 가입 없이 iOS Web Push를 사용할 수 있다. 별도 상용 푸시 대시보드가 필요하지 않다. 전송 서버·구독 저장·재시도는 기존 호스팅 사용량에 포함되므로 전체 운영 무료를 보장하지 않는다.
2. **Firebase Cloud Messaging 대안.** FCM 자체는 무료이고 웹/Android/iOS를 지원한다. 다만 Firebase 프로젝트/키 관리와 SDK 통합이 추가되며 웹의 설치·권한 제약을 없애주지는 않는다. 인증·DB를 Firebase로 옮길 필요는 없다.

iOS/iPadOS 16.4 이상은 홈 화면에 추가한 웹앱에서 사용자가 버튼을 누른 뒤 권한을 요청해야 한다. 일반 Safari 탭에서 앱 실행 직후 권한을 강제로 띄우는 흐름으로 구현하지 않는다. Android/데스크톱도 실제 Push API·Service Worker 지원 여부를 검사한다. 앱 안의 카카오 브라우저 등 미지원 환경에는 외부 브라우저/홈 화면 안내를 제공한다.

## 알림 동의 강제에 대한 권장 의견

앱 전체를 알림 동의로 잠그는 방식은 권장하지 않는다. 미지원 환경·기기 변경·권한 차단 사용자가 기존 신청/환불/운영 연락을 확인할 길까지 막힐 수 있다. 앱 실행 때 이유를 설명하고 사용자가 누른 ‘알림 켜기’에서 OS 권한을 요청하는 안을 제안한다. 거부해도 기존 거래·문의에는 계속 접근할 수 있어야 한다.

- 신청 전과 운영자의 첫 공개 전: 알림을 켜면 받을 중요한 정보를 설명하고 설치/권한 설정 유도.
- 꺼진 상태: ‘앱 밖에서 입금·취소 안내를 받을 수 없어요. 진행 여부를 앱에서 직접 확인해 주세요.’
- 앱 안의 알림 끄기: 진행 중인 신청이 있으면 위 영향을 한 번 안내하고 최종 선택은 존중.
- OS 설정에서 끄기: 앱이 그 순간 경고하거나 해제를 막을 수 없다. 앱 복귀 시 권한·구독 상태를 다시 확인해 알린다. OS 집중 모드 등 모든 전달 차단 상태를 앱이 검출할 수 있는 것은 아니다.
- 미지원/거부 상태를 반복 권한 팝업으로 압박하지 않는다. 거부 뒤에는 브라우저 설정 안내를 제공한다.
- 허용 여부나 전송 서버 접수 성공은 기기의 수신/읽음 증거가 아니다. 푸시만으로 합의·진행 확정·환불 동의를 간주하지 않는다.

## 승인 후 최소 구현안

- manifest, 설치 안내, 푸시 수신 전용 service worker. 인증 API/거래 화면 오프라인 캐시는 만들지 않는다.
- 사용자·기기별 구독 저장/삭제, 본인 권한 검사, 로그아웃/계정 전환/탈퇴 때 이전 계정 연결 해제.
- 검증된 Web Push 라이브러리와 VAPID 비밀키. 프로덕션 의존성 추가는 별도 합의 후 진행.
- 상태 DB 커밋 후 전송. 송신 장애 때문에 입금·취소 자체를 롤백하지 않는다. 작은 재시도 기록/중복 방지, 만료 구독 정리, 실패 건수 확인.
- 잠금 화면에 계좌번호·실명·자기소개를 보내지 않고 ‘참가 상태가 변경됐어요’와 로그인 후 상세 링크 제공.
- 먼저 확정·취소·입금 확인 필요 등 거래 알림만. 마케팅·범용 채팅 푸시는 별도 범위다.
- iPhone 홈 화면 앱과 Android에서 앱을 닫은 수신, 거부/해제, 계정 전환, 만료 구독, 중복 전송, 실패 복구를 실제 기기로 검증.

새 푸시 플랫폼이나 앱스토어 앱보다 위 범위가 단순하다. 다만 현재 기한 안전장치와는 별도 검토 단위이며, 즉시 무조건 도착하는 알림을 보장하는 기능으로 표현하지 않는다.
