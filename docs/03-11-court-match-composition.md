# 코트 매칭의 경기 구성과 제공 불가 처리

작성일: 2026-09-12 · R05 · 구현·검증 완료, 운영 DB 적용 완료·배포 진행

## 확정 정책

새 등록·첫 공개와 시작 3시간 전 진행 판정에 아래 기준을 적용한다. 운영자는 선수 수에 포함하지 않고, 승인/입금 알림이 아닌 참가 확정과 신청 당시 성별을 센다.

| 유형 | 등록·공개 조건 | 진행 판정 |
| --- | --- | --- |
| 혼복 | 최소 4명 이상, 남녀 정원 각각 2명 이상 | 설정한 최소 인원 + 확정 남 2명·여 2명 이상 |
| 남복 | 최소 4명 이상, 남자 자리만 | 최소 인원 이상의 남자 확정 |
| 여복 | 최소 4명 이상, 여자 자리만 | 최소 인원 이상의 여자 확정 |
| 기타 | 최소 2명 이상 | 설정한 최소 인원 확정 |

기존 초안도 첫 공개 때 재검증한다. 이미 공개된 경기는 정책 버전 0으로 보존하고 새 자동 취소 기준을 소급 적용하지 않는다. 일반 매칭과 과거 단식/랠리 기록은 변경하지 않는다.

## 최초 판정과 현재 구성

시작 3시간 전까지 확정된 구성으로 판정하고 통과 시각·인원 근거를 저장한다. 이후 참가 취소가 최초 통과를 되돌리지는 않는다. 현재 구성이 부족하면 **운영자 조치 필요**를 표시한다.

판정 후 추가 모집의 새 신청·승인은 시작 90분 전까지, 해당 승인 신청의 이체는 60분 전까지, 확인은 30분 전까지라는 기존 기한을 유지한다. 판정 전 승인 건은 승인 시 저장한 이체·확인 기한(최대 T-210분/T-180분)을 유지하며 추가 모집 기한으로 연장하지 않는다. 신청이 닫혔다고 확인 중인 신청을 즉시 취소하지 않는다. 보충되면 조치 필요 표시를 해제한다.

제공 불가를 확인한 운영자는 시작 전에 사유를 남겨 취소한다. 현재 PENDING/ACCEPTED/CONFIRMED 신청을 취소하고 실제 수령액 전액을 반환 대상으로 남긴다. 이전 자발적 취소의 금액·사유는 유지한다. 처리 중 송금의 금액·계좌·이력을 덮어쓰거나 자동 이체하지 않는다.

이는 `03-2`의 판정 후 유지 정책에 운영자가 확인한 제공 불가 취소를 연결한 것이다. 대체 경기·시간을 강제하지 않는다. 부분 이용·시작 후 중단·사유 우선순위 재심은 R06/R10의 별도 범위다. 새 크론·외부 알림·의존성을 추가하지 않으므로 정시 통보를 보장하지 않는다.

## 구현과 검증 범위

- Match의 구성 정책 버전은 기존 행 0, 새 운영자 공개 1이다. 최초 통과 시각·인원과 제공 불가 취소의 실제 처리자·요청 번호·사유·구성 근거를 보존한다.
- 계정 거래 공유 잠금 → Match 행 잠금 순서를 유지한다. 취소 직전에 권한·현재 구성·시작 시각을 재검사한다. 보충과 취소가 경합해 구성이 회복됐으면 취소를 거절한다. 동일 요청 재시도는 중복 처리하지 않는다.
- 운영자 홈·시간 관리에 구성 조치 건수를 표시한다. 운영자·참가자 상세에서 진행 조건, 현재 확정 남녀 인원, 입금 확인 기한을 구분한다. 제공 불가 상황을 개인 변심 취소로 안내하지 않는다.
- 혼복 편중·각 유형 최소 인원·정상 구성·최초 판정·판정 후 취소와 보충·중복 취소·권한 없음·기존 공개 보존·송금 중 고정을 검증한다.
