# 코트 매칭 일부 제공 불가 · 부분 반환 설계

2026-10-10 · **합의 금액 기록 구현·검증 완료 / 운영 DB 적용, 앱 배포 진행**.

## 이번에 해결할 문제

우천·시설 문제로 경기 시간 일부만 제공했는데 기존 `운영상 문제 접수`를 사용하면
경기 전체 취소로 처리된다. 반대로 실제 수령액을 줄여 환불을 맞추면 은행 입금 사실을
훼손한다. 이미 있는 참가자/운영자 화면과 환불 실행 기능 안에서 이 예외를 기록한다.
새 송금 연동·정산 시스템·관리 대시보드는 만들지 않는다.

작은 대안은 문의로 사실을 확인하고 수동 송금하는 방식이다. 그러나 앱에 반환 의무와
이미 보낸 금액이 남지 않으면 재송금·누락이 생길 수 있어 최소한의 합의·송금 이력이 필요하다.

## 기존 코드에서 확인한 제약

- `court-slot-service.ts`의 `reportCourtSupplyIncident`는 긴급 사유를 전체 취소로 바꾼다.
  부분 이용 시간이나 부분 반환 기준이 없다.
- `court-match-money.ts`는 실제 수령액, 반환 의무, 기지급액, 처리 중 금액을 구분한다.
  반환 의무 조정과 송금 실행을 계속 분리한다. 초과 입금 반환도 유지한다.
- `startCourtRefund`는 최신 계좌/금액, 중복 요청, 송금 중 잠금을 검증한다. 새 반환액도
  이 경로로 보내며 별도의 송금 버튼/API를 만들지 않는다.
- 기존 신청 안내 v1/v2에는 경기 전체 취소 시 남은 참가자 전액 반환이 들어 있다.
  새 부분 반환 규칙을 과거 신청에 소급해 전액 반환 권리를 줄이지 않는다.

## 사용자 결정

- 미제공 시간 비례 자동 환불 제안은 채택하지 않았다. 사용자는 “코트 운영에서 발생한
  문제들이기에 사용자와 운영자가 서로 연락해서 해결”하는 방식을 선택했다.
- 협의 대상은 중단 당시 확정 참가자이며, 이전 본인 사유 취소는 당시 기준을 유지하는
  권장안을 승인했다. 미확정 종료 신청의 입금은 기존 전액 반환 규칙을 유지한다.
- 앱이 중단 시간으로 부분 반환액을 자동 결정하거나 공·레슨·부상 보상액을 판단하지 않는다.

### 합의 금액 기록 — 사용자 승인

자동 계산 없이 운영자와 참가자가 합의한 금액·사유를 앱에 기록하고 기존 환불 절차로
처리하는 권장안을 승인했다. 실제 수령 기록이나 이전 취소 기록은 변경하지 않는다.
이번 단위에서는 이용 중 발생한 문제를 확정 참가자별로 기록한다. 발생 시각은 예약 이용
시간 안이면서 미래가 아니어야 하고, 그 시점에 이미 확정됐으며 먼저 개인 취소하지 않은
신청만 대상이다. 시작 전 전체 제공 불가는 기존 전액 취소 절차를 사용한다.

합의 금액은 초과 입금을 제외한 **참가비 반환 누적 총액**이다. 초과 입금은 따로 전액
반환하며 기존 정책 반환액과 합의 금액 중 큰 값을 보장한다. 지급·처리 중 금액은 기존
송금 이력에서 차감한다. 같은 금액의 재저장으로 반환액을 가산하지 않는다.
기존 합의 금액은 증가만 가능하며 낮추는 정정은 만들지 않는다. 금액·사유·발생 시각·
입력 담당자·버전·재요청 식별자를 이력에 보존하고 참가자 본인도 확인한다. 앱의 기록은
운영자의 합의 확인 진술이며 당사자의 실제 합의나 은행 송금을 자동 검증한 것이 아니다.

## 합의 금액 기록의 안전 장치

- 운영자는 협의한 반환 금액·사유와 협의 사실을 기록하고 대상자별 금액을 확인한 뒤 확정한다.
  발생 시각과 기록 시각을 구분한다. 사후 기록 때문에 이전 취소자 분류가 바뀌지 않도록
  적용 대상 판단 기준과 기록을 남긴다. 미래의 미제공을 실제 발생한 것처럼 기록하지 않는다.
- 기존의 전체 취소로 기록된 반환 의무나 완료 송금을 부분 반환으로 자동 축소하지 않는다.
  운영자 단독으로 이미 확정된 반환액을 내리는 정정 경로를 만들지 않는다.
- 이미 지급한 금액은 차감하고 초과 입금은 전액 반환한다. 실제 수령보다 더 보내도록
  계산하지 않는다. 손해배상·별도 보상은 이 환불 계산에 섞지 않는다.
- 송금 처리 중인 건의 금액·계좌는 그대로 유지한다. 반환 의무가 추가되면 잔액으로 남겨
  기존 송금 결과를 확인한 다음 처리한다. 중복 클릭/동시 처리로 두 번 가산하지 않는다.
- 계좌가 없어도 합의액 기록은 먼저 완료하고 이번에 구현한 계좌 입력 대기로 이어진다.
- 같은 경기의 운영자 또는 정식 인계 담당자만 처리한다. 계정·경기 잠금 순서를 기존
  금전 작업과 맞추고 버전·재요청 식별자·사유·행위자를 저장한다.
- 일부 이용 후 취소를 ‘전액 반환’으로 안내하지 않는다. 기존 일정·장소·입금 사실을
  변경하지 않고 문제 발생 시각과 반환 사유를 추가로 보여 준다.
- 지각·노쇼·개인의 조기 귀가를 경기 전체의 미제공 시간으로 처리하지 않는다. 공·장비·
  레슨 등 별도 구성의 제공 실패, 개인 부상과 손해배상은 사실 확인이 필요한 별도 문제다.

## 신청 당시 조건 보존

새 신청 안내 v3에는 일부 제공 불가 시 운영자와 협의하는 경로·대상을 명시한다. 신청 당시
안내 버전과 원문은 기존 스냅샷에 남긴다. 이전 안내/안내 누락 신청에도 당사자가 합의한
추가 반환을 기록할 수 있지만 기존 정책 반환액을 낮추지 못한다.
기존 공개 경기의 조건을 몰래 바꾸거나 과거 신청 원문을 덮어쓰지 않는다.

약관의 중요한 조건은 명확히 알리는 방향으로 설계한다([약관법 제3조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1021562635)).
처음 제안한 비례 계산은 철회한 제품 제안이며 법정 환불 기준이 아니다. 책임이나
권리를 일괄 배제하는 조항의 적합성도 별도다([약관법 제7~9조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025032399)).
